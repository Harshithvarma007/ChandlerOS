PDF Processing

Let’s first convert the PDF document into a text document, as text is more flexible for data transformations. Once we have the text document, we need to divide it into chunks.

Once we have the text chunks, we need to transform them into a format that computers can understand. We do this by converting the text into embeddings, which can be used for similarity checks.

Now that we have text embeddings, we store them in a vector store.

A vector store is a specialized database designed to store and manage vector representations of data, often in the form of embeddings. Here’s a detailed explanation:

What is a Vector Store?

Vector Representation: Data (such as text, images, or other types) can be converted into numerical vectors known as embeddings. These vectors are dense, high-dimensional arrays that capture the semantic information of the data. For example, in text processing, a vector might represent the meaning of a word or sentence, allowing comparisons based on their contextual similarity.

Purpose of Vector Stores:

  • Efficient Storage: Vector stores are optimized to store large volumes of vectors in a space-efficient manner and ensure fast access.
  • Similarity Search: They enable efficient similarity search and retrieval by quickly finding vectors close to a query vector using distance metrics like Euclidean distance or cosine similarity.

Key Features:

  • Indexing: Vector stores use indexing techniques (e.g., HNSW, Annoy, Faiss) to speed up similarity searches by creating structures that allow for fast nearest-neighbor queries.
  • Scalability: They handle large-scale data efficiently, enabling quick retrieval of similar vectors even with millions of embeddings.

Common Use Cases:

  • Recommendation Systems: Matching users with similar products or content.
  • Search Engines: Retrieving documents or images similar to a given query.
  • Natural Language Processing: Finding similar sentences or phrases.

Query Handling

To handle user queries, we first convert the query into an embedding, as we can only perform similarity checks with embeddings. Once we have the query embedding, we can compare it with other embeddings in the vector database. After finding the most relevant embedding, we use this chunk as context for Gemini-1.0-pro, which will generate a response based on this context for the user’s query.

PDF to Text Conversion

The get_pdf_text function is responsible for extracting all the text from a PDF document. It works by initializing an empty string, reading the PDF file, and appending the text from each page into this string. Finally, it returns the combined text.

def get_pdf_text(pdf_path):
    """Extracts text from a PDF document."""
    text = ""
    pdf_reader = PdfReader(pdf_path)
    for page in pdf_reader.pages:
        text += page.extract_text()
    return text

Text Chunking

The get_text_chunks function splits the extracted text into manageable chunks. It uses the RecursiveCharacterTextSplitter to divide the text into chunks of up to 10,000 characters, with a 1,000-character overlap between chunks. The function then returns the list of these text chunks.

def get_text_chunks(text):
    """Splits the extracted text into manageable chunks."""
    text_splitter = RecursiveCharacterTextSplitter(chunk_size=10000, chunk_overlap=1000)
    chunks = text_splitter.split_text(text)
    return chunks

Creating a Vector Store

The create_vector_store function creates an in-memory vector store from text chunks. Here’s a quick overview:

  • Initialize Embeddings: It uses GoogleGenerativeAIEmbeddings with a specified model and API key to generate embeddings for the text chunks.
  • Create Vector Store: It then uses FAISS.from_texts to build a vector store from the text chunks and their embeddings.
  • Return Vector Store: Finally, it returns the created vector store.

In summary, this function converts text chunks into embeddings and stores them in a vector database for efficient retrieval.

def create_vector_store(text_chunks):
    """Creates an in-memory vector store from text chunks."""
    embeddings = GoogleGenerativeAIEmbeddings(
        model="models/embedding-001", 
        google_api_key=os.getenv("GEMINI_API_KEY")
    )
    vector_store = FAISS.from_texts(text_chunks, embeddings)
    return vector_store

Generating Responses

The generate_response function creates a detailed and structured response to a question based on the provided context. Here’s a brief explanation:

  • Create Prompt: It formats a prompt template using the provided context and question.
  • Initialize Model: It creates an instance of genai.GenerativeModel with the model name 'gemini-1.0-pro'.
  • Start Chat Session: It begins a chat session with the model.
  • Send Prompt: The formatted prompt is sent to the model, which then retrieves a response.
  • Return Response: Finally, it returns the response text generated by the model.

In essence, this function uses a generative AI model to answer a question using the given context, ensuring that the response is detailed and well-structured.

def generate_response(context, question):
    """Generates a response to a question based on the provided context."""
    prompt_template = """
    Answer the question as detailed as possible from the provided context. Make sure to provide all the details. If the answer is not in the provided context, just say, "The answer is not in the provided context." Do not provide the wrong answer.
    and make the answer more visually attractive, structured and precise.
    Context:\n{context}\n
    Question:\n{question}\n
    Answer:
    """
    
    prompt = prompt_template.format(context=context, question=question)
    
    model = genai.GenerativeModel('gemini-1.0-pro')

    chat_session = model.start_chat(
        history=[]
    )
    response = chat_session.send_message(prompt)
    return response.text

Handling User Input

The user_input function handles user queries by generating a response based on a vector store. Here’s a quick breakdown:

  • Similarity Search: It performs a search in the vector store to find documents relevant to the user’s question. If it fails, an error is logged, and an error message is returned.
  • Extract Context: It combines the text from the retrieved documents into a single context string.
  • Generate Response: The generate_response function is then used to produce an answer based on the context and the user’s question. If this fails, an error is logged, and an error message is returned.
  • Return Response: Finally, the function returns the generated response.

In summary, this function searches for relevant documents, extracts context, and generates a response while handling potential errors.

def user_input(user_question, vector_store):
    """Handles user input and generates a response based on the in-memory vector store."""
    try:
        # Perform similarity search
        docs = vector_store.similarity_search(user_question)
    except Exception as e:
        st.error(f"Failed to perform similarity search: {e}")
        return "Error: Unable to perform the similarity search."

    # Extracting text from the retrieved documents
    context = "\n".join([doc.page_content for doc in docs])

    try:
        # Generate response using the custom function
        response = generate_response(context, user_question)
    except Exception as e:
        st.error(f"Failed to generate response: {e}")
        return "Error: Unable to generate a response."

    return response

import streamlit as st
from PyPDF2 import PdfReader
from langchain.text_splitter import RecursiveCharacterTextSplitter
from langchain_google_genai import GoogleGenerativeAIEmbeddings
import google.generativeai as genai
from langchain.vectorstores import FAISS
import os
import tempfile

# Load environment variables
from dotenv import load_dotenv
load_dotenv()

# Configure Google Gemini API key from environment variables
genai.configure(api_key=os.getenv("GEMINI_API_KEY"))

# Retrieve login credentials from Streamlit secrets
VALID_USERNAME = st.secrets["USER_NAME"]
VALID_PASSWORD = st.secrets["PASSWORD"]

def generate_response(context, question):

def main():
    """Main function to run the Streamlit app."""
    st.set_page_config(page_title="Chat PDF", layout="wide")

    # Single Column Layout
    st.header("Chat PDF")

    if 'logged_in' not in st.session_state:
        st.session_state.logged_in = False

    if not st.session_state.logged_in:
        st.subheader("Login")
        username = st.text_input("Username")
        password = st.text_input("Password", type="password")

        if st.button("Login"):
            if username == VALID_USERNAME and password == VALID_PASSWORD:
                st.session_state.logged_in = True
                st.session_state.image_index = 0  # Initialize image index
                st.success("Login successful!")
            else:
                st.error("Invalid username or password")
        return  # Exit early to not show the main app while not logged in

    # PDF Upload Section
    pdf_file = st.file_uploader("Upload PDF", type="pdf")
    if pdf_file:
        # Extract text from the PDF and create an in-memory vector store
        pdf_text = get_pdf_text(pdf_file)
        text_chunks = get_text_chunks(pdf_text)
        vector_store = create_vector_store(text_chunks)
        st.session_state.vector_store = vector_store  # Store in session state

    # Query Section
    user_question = st.text_input("Ask a Question")

    if user_question:
        if 'vector_store' in st.session_state:
            vector_store = st.session_state.vector_store
            response = user_input(user_question, vector_store)
            st.write("## Reply:")
            st.write(response)
        else:
            st.write("Please upload a PDF to begin.")

if __name__ == "__main__":
    main()
