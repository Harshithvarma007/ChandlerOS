What is SMOTE? 🤖

SMOTE addresses class imbalance by generating synthetic samples for the minority class:

  1. Addressing Class Imbalance: SMOTE tackles the problem where one class (usually minority) has far fewer samples than another class (majority), which can lead to biased models.
  2. Generating Synthetic Samples: It creates new instances by interpolating between existing minority class samples in the feature space.
  3. Interpolation Technique: SMOTE selects pairs of similar instances from the minority class and creates synthetic instances along the line segments joining these pairs.
  4. Maintaining Data Distribution: Synthetic samples maintain the distribution and patterns of the minority class, preventing overfitting and improving model generalization.

What is a Vectorizer? 🎨

Text to Numerical Conversion: A vectorizer transforms text data into numerical vectors that machine learning algorithms can process. In NLP, algorithms work with numerical data, so we transform text into a format they comprehend.

Feature Extraction: Vectorizers extract features from text by converting words or phrases into numerical values. These features capture crucial information like word frequency.

Dimensionality Reduction: They can reduce text data’s dimensionality by creating matrices where rows are documents and columns are unique words — a sparse representation.

Why Use Vectorizers? 🚀

  • Input Format for Models: ML models need numerical input. Vectorizers convert raw text into a format models can learn from.
  • Feature Representation: Captures word importance and relationships, aiding models in learning patterns and making predictions.
  • Efficient Data Representation: Provides compact representations, crucial in high-dimensional spaces with many unique words.
  • Normalization and Scaling: Although Count Vectorizers don’t normalize or scale inherently, their output can be processed further for better ML algorithm performance.
  • Handling Sparse Data: Efficiently manages sparse text data, storing only non-zero values, saving memory and computation.

In summary, Count Vectorizers are vital for converting text into numerical form, enabling ML models to effectively process and learn from textual data. They capture word frequency, essential for understanding text content and context. 📝

Deployment 🚀

In this section, I’ll guide you through deploying your application on AWS, the easiest way possible! We’ll create a dedicated deployment branch and set up everything you need for a smooth deployment.

Step-by-Step Deployment Guide 🚀

  1. Create a Deployment Branch:
  • Start by creating a separate branch called Deployment in your project repository. This branch will only contain the necessary files for deployment.

📁 Deployment Branch Structure:

  • app.py: A basic Streamlit application that loads models and vectorizers for predictions.
  • requirements.txt: Lists essential dependencies including:
streamlit
joblib
tensorflow
Pillow

The advantage of a deployment branch is that it significantly reduces the space and libraries required for deployment.

  1. Set Up AWS Instance:
  • Log in to your AWS Console and navigate to EC2

Launch Instance:

  • Click on “Launch Instance” and follow the setup instructions below:
  • Make sure to select an appropriate instance type and configuration. Click “Launch Instance” to proceed.

Configure Security Groups:

  • After launching your instance, ensure that it’s running. Click on the instance ID and navigate to the Security tab.
  • Edit inbound rules to expose port 8501 (Streamlit’s default port).

Connect to Your Instance:

  • Go back to your instance details and click on “Connect”.
  • Follow the instructions to connect to your instance using SSH.

#!/bin/bash

# Update the package lists and install updates
echo "Updating package lists and installing updates..."
sudo apt update
sudo apt upgrade -y

# Install Python 3, pip, virtualenv, and Git
echo "Installing Python 3, pip, virtualenv, and Git..."
sudo apt install -y python3-pip python3-venv git

# Clone the repository (replace with your actual repository URL if different)
echo "Cloning the repository..."
git clone -b Deployment https://github.com/Harshithvarma007/Spam-email.git
cd Spam-email  # Adjust this to your repository's directory structure

# Set up virtual environment
echo "Setting up virtual environment..."
python3 -m venv venv
source venv/bin/activate

# Install Python dependencies
echo "Installing Python dependencies..."
pip install -r requirements.txt

# Create systemd service file for Streamlit
echo "Creating systemd service file..."
cat <<EOF > streamlit.service
[Unit]
Description=Streamlit Web Application

[Service]
Type=simple
ExecStart=$(pwd)/venv/bin/streamlit run $(pwd)/app.py --server.port 8501
WorkingDirectory=$(pwd)
User=ubuntu
Group=ubuntu
Restart=always

[Install]
WantedBy=multi-user.target
EOF

# Move systemd service file to /etc/systemd/system/
echo "Moving systemd service file to /etc/systemd/system/..."
sudo mv streamlit.service /etc/systemd/system/

# Reload systemd to read the new service file
echo "Reloading systemd..."
sudo systemctl daemon-reload

# Enable and start Streamlit service
echo "Enabling and starting Streamlit service..."
sudo systemctl enable streamlit
sudo systemctl start streamlit

# Check Streamlit service status
echo "Streamlit service status:"
sudo systemctl status streamlit

Make it executable:

chmod +x deploy.sh

Run the script:
