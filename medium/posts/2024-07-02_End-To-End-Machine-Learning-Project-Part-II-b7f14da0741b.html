Template Creation

NERD: Why is a template required?

A template is essential because it ensures uniformity across all projects and reduces the manual effort needed to create folders and files each time you start a new project. With a template, you can maintain a proper structure and uniformity throughout all your end-to-end projects.

You need only one file, template.py, to serve as the template for all your projects from now on.

5. File and Directory Creation:

  • The code iterates over each filepath in the list_of_files.
  • filepath = Path(filepath): Converts the string path to a Path object for easier manipulation.
  • filedir, filename = os.path.split(filepath): Splits the filepath into the directory (filedir) and the file name (filename).
  • if filedir != "":: Checks if filedir is not an empty string, which means the file is located in a directory structure.
  • os.makedirs(filedir, exist_ok=True): Creates the directory (and any intermediate directories) if it doesn't exist. The exist_ok=True parameter prevents raising an error if the directory already exists.
  • logging.info(f"Creating directory: {filedir} for the file: {filename}"): Logs a message indicating that the directory is being created.
if not os.path.exists(filepath) or os.path.getsize(filepath) == 0:

6. File Creation:

  • if not os.path.exists(filepath) or os.path.getsize(filepath) == 0:: Checks if the file does not exist or if its size is zero (i.e., it's empty).
  • with open(filepath, "w") as f: pass: Creates an empty file if the above condition is true. The pass statement is used as a placeholder because we only need to create the file without writing any content to it.
  • logging.info(f"Creating empty file: {filepath}"): Logs a message indicating that an empty file is being created.
  • else: logging.info(f"{filename} already exists"): If the file already exists and is not empty, logs a message indicating that the file already exists.

    format= logging_str,

import os
from box.exceptions import BoxValueError
import yaml
from Toxic_comment_detection import logger
import json
import joblib
from ensure import ensure_annotations
from box import ConfigBox
from pathlib import Path
from typing import Any



@ensure_annotations
def read_yaml(path_to_yaml: Path) -> ConfigBox:
    """reads yaml file and returns

    Args:
        path_to_yaml (str): path like input

    Raises:
        ValueError: if yaml file is empty
        e: empty file

    Returns:
        ConfigBox: ConfigBox type
    """
    try:
        with open(path_to_yaml) as yaml_file:
            content = yaml.safe_load(yaml_file)
            logger.info(f"yaml file: {path_to_yaml} loaded successfully")
            return ConfigBox(content)
    except BoxValueError:
        raise ValueError("yaml file is empty")
    except Exception as e:
        raise e


@ensure_annotations
def create_directories(path_to_directories: list, verbose=True):
    """create list of directories

    Args:
        path_to_directories (list): list of path of directories
        ignore_log (bool, optional): ignore if multiple dirs is to be created. Defaults to False.
    """
    for path in path_to_directories:
        os.makedirs(path, exist_ok=True)
        if verbose:
            logger.info(f"created directory at: {path}")


@ensure_annotations
def save_json(path: Path, data: dict):
    """save json data

    Args:
        path (Path): path to json file
        data (dict): data to be saved in json file
    """
    with open(path, "w") as f:
        json.dump(data, f, indent=4)

    logger.info(f"json file saved at: {path}")




@ensure_annotations
def load_json(path: Path) -> ConfigBox:
    """load json files data

    Args:
        path (Path): path to json file

    Returns:
        ConfigBox: data as class attributes instead of dict
    """
    with open(path) as f:
        content = json.load(f)

    logger.info(f"json file loaded succesfully from: {path}")
    return ConfigBox(content)


@ensure_annotations
def save_bin(data: Any, path: Path):
    """save binary file

    Args:
        data (Any): data to be saved as binary
        path (Path): path to binary file
    """
    joblib.dump(value=data, filename=path)
    logger.info(f"binary file saved at: {path}")


@ensure_annotations
def load_bin(path: Path) -> Any:
    """load binary data

    Args:
        path (Path): path to binary file

    Returns:
        Any: object stored in the file
    """
    data = joblib.load(path)
    logger.info(f"binary file loaded from: {path}")
    return data



@ensure_annotations
def get_size(path: Path) -> str:
    """get size in KB

    Args:
        path (Path): path of the file

    Returns:
        str: size in KB
    """
    size_in_kb = round(os.path.getsize(path)/1024)
    return f"~ {size_in_kb} KB"

Functions:

  • read_yaml: Reads a YAML file and returns its contents wrapped in a ConfigBox object.
  • create_directories: Creates directories specified in a list of paths, with an option to log the creation.
  • save_json: Saves Python data structures as JSON into a specified file path.
  • load_json: Loads JSON data from a specified file path into a ConfigBox object.
  • save_bin: Saves binary data into a specified file path using joblib.
  • load_bin: Loads binary data from a specified file path using joblib.
  • get_size: Calculates and returns the size of a file in kilobytes (KB).

These utility functions provide general-purpose functionality that can be utilized across various end-to-end machine learning projects. They handle operations such as file handling (JSON, binary), directory creation, YAML file reading, and file size retrieval, ensuring efficient and organized project management.
